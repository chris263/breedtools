# Print a single-stage analysis

Print a single-stage analysis

## Usage

``` r
# S3 method for class 'single_stage_analysis'
print(x, n = 10, ...)
```

## Arguments

- x:

  An object returned by
  [`analyze_single_stage()`](https://solgenomics.github.io/breedtools/reference/analyze_single_stage.md).

- n:

  Number of top-ranked genotypes to show.

- ...:

  Unused.

## Value

Invisibly returns `x`.
