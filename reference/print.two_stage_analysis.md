# Print a two-stage analysis

Print a two-stage analysis

## Usage

``` r
# S3 method for class 'two_stage_analysis'
print(x, n = 10, ...)
```

## Arguments

- x:

  An object returned by
  [`analyze_two_stage()`](https://chris263.github.io/breedtools/reference/analyze_two_stage.md).

- n:

  Number of top-ranked genotypes to show.

- ...:

  Unused.

## Value

Invisibly returns `x`.
